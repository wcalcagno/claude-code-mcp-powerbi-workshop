Setup

Git, GitHub y Claude Code funcionando en tu computador.

Bloque práctico. Quince minutos, y es el que más se atrasa. Táctica: no esperes a que los cuarenta terminen. Parte con los que ya tienen todo instalado ayudando a los de al lado. Levanta la mano quien ya tenga git --version respondiendo. El cuello de botella clásico es el token de GitHub. Si alguien se atasca ahí más de cinco minutos, que siga con Claude Code y vuelva al token en el break — no bloquea nada hasta el bloque 4. Recordar en voz alta: cerrar y abrir PowerShell después de cada instalación. La mitad de los "no me funciona" de este bloque son eso.
