Bloque 01 · Claude Code

Los comandos esenciales

Escribes Y pasa esto
cd carpeta Te mueves al proyecto. Hazlo siempre antes de abrir Claude Code.
claude Inicia la sesión sobre esa carpeta.
@archivo Le entregas ese archivo como contexto.
/mcp Ves los servidores conectados. Lo vas a usar todo el día.
/clear Limpias la conversación y parte de cero.
Esc Lo interrumpes si está haciendo algo que no querías.
/exit Vuelves a PowerShell.

Siete comandos y no hay que memorizarlos. Los dos que de verdad importan hoy son cd, porque si abren Claude Code en la carpeta equivocada no va a ver nada del taller, y /mcp, que es el semáforo de los dos bloques siguientes. Aclarar la diferencia que confunde a todo el mundo: lo que escribes empezando con barra es una instrucción para la herramienta. Todo lo demás es un mensaje para Claude, en español normal. Mencionar Esc con énfasis: mucha gente no sabe que puede interrumpir y se queda mirando la pantalla mientras el asistente hace algo que no quería. Tienen el control en todo momento. Y el consejo que más van a usar: cuando algo falle, copien el error completo y péguenlo en Claude Code preguntando qué significa.
