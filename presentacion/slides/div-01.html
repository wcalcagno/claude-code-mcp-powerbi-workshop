Claude Code básico

Crear un archivo, revisarlo y guardarlo en el historial. Sin escribir un comando de Git a mano.

Quince minutos, y el objetivo real no es el archivo: es que pierdan el miedo a la caja de texto. Insistir en una cosa: acá ya no están escribiendo comandos de PowerShell. Le están hablando a Claude en español normal. Mucha gente se queda pegada tratando de escribir "correctamente" y no hace falta. El ejercicio es crear mis-notas.md y commitearlo. Cuando aparezca el primer cuadro de permisos, parar la sala y leerlo juntos en voz alta. Es la primera vez que lo ven y conviene que sea guiado. Al final, mostrar el git log. Que vean que el commit tiene su nombre. Eso hace clic.
