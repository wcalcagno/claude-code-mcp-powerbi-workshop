Claude Code conectado al modelo que tienes abierto ahora mismo en Power BI Desktop.

Antes de decir una palabra: que todos abran Power BI Desktop con un .pbix cargado. Ahora. Esperar a que la sala lo haga. Este es el bloque que más impresiona, así que vale la pena que parta bien. El primer prompt que vean funcionar sobre su propio modelo es el momento en que el taller se gana a la audiencia. Los dos errores que van a aparecer, en este orden de frecuencia: Power BI Desktop cerrado o en la pantalla de bienvenida, y no haber reiniciado Claude Code después de registrar el servidor. Ten las dos respuestas listas. Y cuando alguien pregunte si puede pedirle que cree una medida: perfecto, es la pregunta que queremos. La respuesta es no, y el porqué es la slide del fondo naranjo.
